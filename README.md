# Eduardo Zambrano - Academic Website

Personal academic portfolio website for Professor Eduardo Zambrano, hosted on GitHub Pages.

**Live site:** [eduardo-zambrano.github.io](https://eduardo-zambrano.github.io/)

## Pages

- **Homepage** - Bio, contact information, research interests
- **Research** - Published papers and working papers with descriptions and links
- **Teaching** - Archived teaching effectiveness research
- **Links** - Personal interests

## Built With

- HTML5/CSS3/JavaScript
- Bootstrap 3
- Based on the "Air" template from [FreeHTML5.co](http://freehtml5.co/)

## Deployment

The site deploys automatically to GitHub Pages when pushed to the `main` branch.

```bash
git add .
git commit -m "message"
git push origin main
```
